TechCrunch รายงานเมื่อ **2 ตุลาคม 2026** ว่า Apple จะเพิ่มการควบคุม **Full Disk Access** บน macOS โดยอ้างว่า AI agent generation ใหม่ทำให้ความเสี่ยงเพิ่มขึ้น "substantially" — permission นี้เดิมออกแบบไว้ให้โปรแกรม backup ทำงาน แต่ developer บางรายกำลังใช้ในลักษณะที่เปิด files, mail, messages และ browsing history ให้ app โดย user ไม่ทันเข้าใจเต็มที่; Apple ประกาศจะ "introduce additional controls to ensure that users who genuinely wish to grant an app this extraordinary level of access can only do so with very explicit user action"; การเคลื่อนไหวตามหลังข่าวนักข่าวกล่าวหา **Meta Muse Mac app** อ่าน private message (Meta ปฏิเสธ) และ report แยกจาก Wired เรื่อง bug ใน **ChatGPT Mac app** ที่อาจเปิดเผย sensitive data

เคสนี้เป็น case study ตรงจุดในวิชา OS/security — permission model ปี 2020 ที่ออกแบบไว้สำหรับ "โปรแกรม backup" ถูก AI agent repurpose เป็นช่องอ่าน mail/message/browsing แบบไม่มี granular consent; threat model เปลี่ยนจาก "app ที่ user เลือก install เอง" เป็น "agent ที่ user เพียง delegate เป้าหมาย" และเรียก API ซ้ำ ๆ โดย user ไม่ทันเห็น action แต่ละครั้ง ซึ่งเป็นปัญหาเชิง alignment ที่อยู่ **รอบนอก model** ไม่ใช่ภายใน — permission system ไม่ได้ออกแบบให้ถาม consent per-action แต่เป็น per-install สำหรับ macOS dev ที่ขอ Full Disk Access สำหรับฟีเจอร์ AI assistant เตรียม refactor ให้ใช้ scoped bookmark + user-granted folder แทนที่จะพึ่ง blanket permission ก่อน Apple ปล่อย beta ของ API ใหม่; ถ้าจำเป็นต้องขอจริง UX ควร rebuild เพื่อ "explicit per-session re-authorization" ที่ Apple น่าจะบังคับ
