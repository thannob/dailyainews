### 4. OpenAI เสนอวิธีวัดความสามารถโมเดล AI แบบใหม่ เพื่อประเมินขีดจำกัดได้ดีขึ้น — [Blognone](https://www.blognone.com/node/152239)

Jakub Pachocki หัวหน้าฝ่ายวิทยาศาสตร์ของ OpenAI เสนอให้ใช้ perplexity เป็นมาตรวัดกลางของ AI progress ที่ใช้เปรียบเทียบข้าม lab ได้ พร้อมเผยแพร่ตัวเลข internal perplexity ของ OpenAI ด้วย หลักการคือ perplexity ที่ต่ำลงหมายถึงโมเดลทำงานได้ดีขึ้น แม้จะมีข้อจำกัดเรื่องการเลือก reference model และ dataset ที่ต่างกันอาจทำให้เปรียบเทียบยาก

ในเชิงการศึกษา ข้อเสนอนี้สะท้อนการยอมรับกลาย ๆ ว่า benchmark ที่ใช้กันอยู่ (MMLU, HumanEval, ARC) กำลัง saturate หรือถูก train-on-test จน overclaim ได้ง่าย perplexity เป็น metric เก่าแก่แต่ปัญหาหลักคือมันขึ้นกับ reference model และ tokenizer อย่างมาก การเปรียบเทียบข้ามโมเดลที่ใช้ tokenizer ต่างกันแทบไม่มีความหมายในเชิงสัมบูรณ์ และ perplexity ไม่ได้ correlate กับ downstream task performance เสมอ ข้อเสนอจึงมีคุณค่าในฐานะ guard rail กันการ overclaim ว่า saturate benchmark แล้ว มากกว่าในฐานะมาตรวัดเดี่ยว ในทางปฏิบัติ practitioner ที่ต้องเลือกโมเดลให้ทีม อย่าเพิ่งเปลี่ยนไปใช้ perplexity เป็นเกณฑ์หลัก ควรวัดด้วย task-specific eval ที่ทีมสร้างเอง (golden set + LLM-as-judge) และใช้ perplexity ช่วย sanity-check ว่าโมเดลใหม่ไม่ได้ regress เรื่องพื้นฐาน ไม่ควรใช้ตัดสิน production decision
